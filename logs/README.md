# NetSec Logs Directory

This directory contains log files generated by the NetSec Rust application.

## Log Files

When NetSec runs, it will create the following log files:

- `netsec.log` - General application logs
- `arp_spoof.log` - ARP spoofing detection events
- `dos_attack.log` - DoS attack detection events  
- `brute_force.log` - Brute force attack attempts
- `new_device.log` - New device detection events
- `alert.log` - All security alerts

## Log Format

Logs are written in structured JSON format for easy parsing and analysis:

```json
{
  "timestamp": "2024-01-01T12:00:00.000Z",
  "level": "WARN",
  "target": "arp_spoof",
  "fields": {
    "mac": "aa:bb:cc:dd:ee:ff",
    "ip": "192.168.1.100",
    "message": "ARP spoofing detected"
  }
}
```

## Log Rotation

Logs are automatically rotated daily and old logs are cleaned up according to the configuration in `config.toml`.

## Analysis

You can analyze logs using standard JSON tools:

```bash
# View recent alerts
tail -f logs/alert.log | jq .

# Count ARP spoofing events
grep "ARP spoofing" logs/arp_spoof.log | wc -l

# Find all events from a specific IP
grep "192.168.1.100" logs/*.log
```
